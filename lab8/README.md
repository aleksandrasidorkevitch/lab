# Задача 25: Учёт посещаемости занятий

**Студент:** Сидоркевич А.В.

## Постановка задачи
Разработка документации для системы учёта посещаемости занятий.
- **Пользовательские сценарии:** отметить присутствие группы на занятии, выгрузить процент посещаемости для конкретного студента.
- **Технические аспекты:** модели данных "Занятие" (Class) и "Студент" (Student), логика расчёта процента посещаемости и выявления студентов ниже установленного порога.
- **OpenAPI:** спецификация должна включать операции для получения списка занятий, добавления отметки о присутствии, получения процента посещаемости студента и получения списка студентов с посещаемостью ниже порога.
