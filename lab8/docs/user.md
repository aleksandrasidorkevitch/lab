# Руководство пользователя: Система учёта посещаемости

## О системе
Система позволяет преподавателям и старостам отмечать присутствие студентов на занятиях, а студентам — проверять свой процент посещаемости.

## Основные сценарии

### Как отметить присутствие группы на занятии
1. Преподаватель или староста открывает список занятий
2. Выбирает нужное занятие (по дате и предмету)
3. Отмечает присутствующих студентов (или всех сразу, если группа полная)
4. Система сохраняет отметки и автоматически пересчитывает статистику

**Важно:** Отметить можно только существующее занятие из списка. Нельзя создать новую отметку для несуществующего занятия.

### Как посмотреть процент посещаемости студента
1. Студент или преподаватель запрашивает статистику по ID студента
2. Система возвращает процент посещаемости (сколько занятий посещено / общее количество занятий)
3. Дополнительно показывается количество пропущенных занятий

**Пример:** Студент посетил 15 из 20 занятий → процент посещаемости 75%

### Как получить список студентов с низкой посещаемостью
1. Преподаватель запрашивает список студентов, у которых посещаемость ниже установленного порога (например, ниже 70%)
2. Система возвращает список с ID, ФИО и процентом посещаемости
3. Это помогает выявить студентов, которым грозит отчисление или допуск к экзамену

**Порог посещаемости:** Обычно 70%, но может настраиваться в системе.

## Частые ошибки и FAQ

**Вопрос:** Почему я не могу отметить присутствие на занятии, которого нет в списке?  
**Ответ:** Сначала нужно создать занятие в системе (это делает администратор или преподаватель через отдельный интерфейс).

**Вопрос:** Что делать, если студент присутствовал, но его забыли отметить?  
**Ответ:** Преподаватель может добавить отметку задним числом, но только для существующего занятия.

**Вопрос:** Как узнать свой ID студента?  
**Ответ:** ID выдаётся при регистрации в системе или его можно узнать у старосты/преподавателя.

**Вопрос:** Процент посещаемости считается по всем предметам или отдельно по каждому?  
**Ответ:** По всем предметам суммарно. Если нужна детализация по предметам — это отдельная функция (в текущей версии не реализована).

## Ограничения системы
- Нельзя отметить присутствие на будущее занятие (только прошедшее или текущее)
- Нельзя удалить отметку о присутствии (только изменить статус через администратора)
- Процент посещаемости обновляется автоматически после каждой отметки
